# Notes

Keep arguments, examples, computational evidence, partial ideas, source
checks, and informative unsuccessful attempts here. Give each note a clear
title, date, short description, and relevant links.

State the support and limitations of mathematical claims. A note can simply
preserve a question or an idea; it need not claim a result.

Preserve substantive earlier work. Mark a superseded note with a link to its
replacement. Generated data should identify its producing method and scope.
Keep large computational artifacts separate from the human-readable account.
