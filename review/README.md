# Review workspace

Create one directory per review project. Preserve fixed review units, reports,
focused responses, and a concise outcome record. Do not copy journal entries,
confidence signals, or unrelated computations into blind referee packets.

The templates here are starting forms rather than mandatory bureaucracy:

- `templates/claim-register.md`
- `templates/cleaning-report.md`
- `templates/referee-packet.md`
- `templates/referee-report.md`
- `templates/response.md`
- `templates/outcome.md`

Use `../method/review.md` for the distinction between collaborative cleaning,
blind correctness review, focused reassessment, and fresh review.
