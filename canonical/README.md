# Current load-bearing knowledge

Keep this directory concise. An entry belongs here when other work depends on
it and its support can be described accurately. Canonical does not mean certain.

For each entry, record:

- A stable identifier and a precise statement with its hypotheses.
- Support: argument, computation with range, independent review, or cited source.
- Dependencies, with stable identifiers where available.
- Provenance sufficient to recover the argument, evidence, or review.
- Concrete conditions under which its justification would fail.

If support is withdrawn, archive the entry in `notes/retracted/` with the
reason and date. Remove dependent entries from current use transitively
before considering whether they have independent support. Preserve the
history and record the correction in the journal.

No claims are supplied by this template.
