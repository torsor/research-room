# Research questions

Use one short file per substantial question. State:

- What we want to understand and why it matters.
- The relevant objects and hypotheses, referring to `conventions.md`.
- What currently informs the question, with links to the supporting artifacts.
- What remains uncertain and the next useful action, if one is agreed.

These files describe the current state and may be rewritten as understanding
changes. Preserve significant changes of direction in the journal. Historical
instructions should not remain phrased as present tasks.

No research questions are assigned by this template.
