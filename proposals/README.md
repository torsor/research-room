# Proposal workspace

Use this directory only for proposal reviews requested by the user or justified
under `../method/proposals.md`. A small bounded exploration needs no proposal.

The templates support piecewise clarity, assessment, and response:

- `templates/proposal.md`
- `templates/clarity-report.md`
- `templates/panel-report.md`
- `templates/response.md`

Preserve reports, but keep the current proposal and decision easy to find.
